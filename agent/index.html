How to Set Up Your AI

GEMINI Option 1: Google Gemini (Cloud)

Free API key from Google. Works from anywhere — GitHub Pages, local, etc.

1

Go to Google AI Studio and sign in with your Google account.

2

Click "Create API Key" and copy the key (starts with AIza...).

3

Select Gemini Flash above and paste the key.

OLLAMA Option 2: Ollama (Local, Free, Private)

Runs on your computer. No API key needed. Completely private. Requires ~8GB+ RAM for a good model.

1

Install Ollama from ollama.com/download

2

Pull a model in terminal:
ollama pull llama3

3

Allow browser access — run in terminal:
OLLAMA_ORIGINS="*" ollama serve

4

Open https://localhost:8443/api/tags in your browser and accept the security warning (self-signed cert).

5

Select Ollama (Local) above, enter the URL https://localhost:8443, type your model name, and chat!

Recommended models: qwen3.6 (best quality), gemma4 (fast + smart), nemotron (most capable), deepseek-r1 (reasoning). Type any model name in the field above.
