# Bible Prophecy: Adult Edition

An adult Bible-study quiz based on the supplied Daniel and Revelation question set, expanded to 560 questions. It supports one player or two players sharing one device, with separate scores and streaks. Difficulty increases over the match, with a bonus round every fifth question.

## Daniel ↔ Revelation mirror path

The 560 questions are arranged as twenty paired gates. Each gate produces fourteen Daniel/Revelation question pairs that repeatedly test the anchor, counterpart, references, thematic bridge, and interpretative direction. The in-game mirror display identifies the active book, the connecting theme, and the study bridge. This uses the supplied Adventist historicist framing; its connections are study prompts and not a claim that every pair is an identical event.

Each new match randomizes the order of the mirror gates and independently shuffles every question’s answer choices. The Daniel → Revelation pair remains intact, so the topology is preserved while the match cannot be memorized by position.

## Music and narration

The opening screen has opt-in controls for gentle generated ambient music and voice narration. The soundtrack, answer chimes, and spoken prompts use the browser’s local audio/speech features; no external recordings, tracking, or copyrighted music files are bundled. Either control can remain off for a quiet group-study setting.

## Competitive play

- Timers shorten as difficulty rises (24 seconds down to 10 seconds).
- Correct answers combine level points, speed bonus, and streak bonus.
- Every fifth question is a double-base-points bonus round.
- Each player has one Double Score power play per match.
- In a two-player match, an incorrect or timed-out answer opens a seven-second steal window for the opponent at reduced points.
- The live score board shows the leader; a tied final score is settled by total correct-answer time.

The mechanics reward quick recall, but every question still reveals the answer, Scripture reference, and any interpretive note for discussion.

## Run locally

Open `index.html` in a modern browser, or install the declared Electron development dependency and run `npm start`.

## Theological framing

Questions state Scripture references with their answers. Notes marked **Adventist historicist study note** retain the supplied source's Seventh-day Adventist interpretation, rather than presenting that interpretation as a cross-tradition consensus.

## Scope of this stage

This is the unlicensed playable game stage. A real license flow requires an approved server, database, and public privacy/contact details; it should not be replaced by a client-side gate.
